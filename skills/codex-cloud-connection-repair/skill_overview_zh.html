Codex 云连接诊断与定向修复

v0.1.0 · 可复用诊断 skill 与受控修复手册

适用场景

云环境可见，但设置聊天无法开始；云 WebSocket 超时；重试创建后出现多个同名环境。

目标：定位失败层，执行已授权的最小修复，并用原应用的真实结果验收。

五层证据

  1. 环境配置已登记
  2. TLS / HTTP 路径可达
  3. 原 Desktop 云连接已初始化
  4. 云端请求成功
  5. 原任务实际执行成功

上一层成功不能代替下一层验收。

包含内容

轮转日志摘要、直连与本地代理对比、单域名转发适用条件、精确回滚、重复环境判断。

脚本只读诊断；修改系统解析、代理及云数据需要相应授权。无固定 IP 的自动安装器。

实际验证边界

一个 Windows 案例已恢复云连接和云聊天读取；完整云任务执行与无人值守运行尚未在该案例中验证。

临时转发需要明确退出和重启方案，不能留下指向已停止进程的 hosts 映射。
